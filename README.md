# LOGIC
the homepage accepts user's name, institutions email. students ID and their interest, all these are monitored by regex patterns using inline input validation on the user's end, submitting their details leads them to where the matching occurs.


on the quiz page. we have a live timer dispaly when the quiz starts, the user then answers a set of nine questions.

after the quiz, the website then recommends the pillars they are leaning more towards and a visula is also provided for the different global citizenship and goals.

the homepage has the users details and a feedback/inquiry  form
